title: "Web Developer Toolbar päivittyy"
date: 2005-09-14
categories: 
  - "it"
---

Chris Pederickin Web Developer Toolbar on saanut päivityksen versioon 0.9.4. Ei uusia ominaisuuksia, pelkästään yhteensopivuutta Firefox 1.5 versiota silmällä pitäen. Myös IE-selaimelle on kehitetty testaukseen erinomainen Web Accessibility Toolbar, lataa omasi [http://www.nils.org.au/ais/](http://www.nils.org.au/ais/).
