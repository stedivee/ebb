On taas se päivä kuukaudessa, **oma tietoturvapäivä**. Microsoft jakaa joka kuukauden toisena tiistaina tietoturvapäivitykset Windows Update -palvelunsa kautta, tosin tänne Suomeen päivitykset valuvat usein vasta myöhään tiistai-iltana tai keskiviikon puolella. Itselläni on edelleen muutama Windows -kone käytössä, vaikka ykköskoneeni onkin Chromebook, sillä kirjoittelenkin tätä artikkelia. **Olen allokoinut kalenteristani tämän päivän oma tietoturvapäiväksi**, jolloin päivitän joka kuukausi kaikki muutkin koneeni ja laitteeni sekä käyn läpin tärkeimpien tilien tietoturva-asetukset.

<!--more-->

Eräällä tavalla siis Microsoft tahdittaa omaa tietoturvapäivääni. Tämä on osoittautunut hyväksi tavaksi, asiat tulee oikeasti tehtyä säännöllisesti. Ei tietoturvasta huolehtiminen toki rajoitu vain kertaan kuukaudessa, päivityksiä ohjelmiin tapahtuu toki viikoittain, joskus jopa päivittäin, sillä mm. selaimet ja muut ohjelmat päivittyvät omaan tahtiinsa. Sen lisäksi on välillä akuutteja tietoturvariskejä, joita ilmenee säännöllisesti maailmalla, silloin joutuu ehkä reagoimaan nopeastikin.

## Oma tietoturvapäivä - työlistaa

Tässä muutamia asioita joita pyrin hoitamaan omana tietoturvapäivänäni.

### Windows koneet

- Windows Update päivitykset
- Turhien ohjelmien poisto, mikäli kuukauden aikana on kokeillut jotain uutta
- Täysi skannaus virustorjuntaohjelmalla

### Linux

- Päivitykset
- Turhien ohjelmien poisto, mikäli on kokeillut jotain uutta

### Android

- Päivitykset käyttöjärjestelmään
- Turhien ohjelmien poisto, mikäli on kokeillut jotain uutta
- Ohjelmien päivitykset
- Samalla Google -tilin tietoturvatarkistus

### iOS

- Päivitykset käyttöjärjestelmään
- Turhien ohjelmien poisto, mikäli on kokeillut jotain uutta
- Ohjelmien päivitykset
- Apple -tilin tietoturvatarkistus

### IoT

- kodin IoT -laitteiden ohjelmistopäivitysten tarkistus

Kyllä näitä tarkistettavia kohteita on paljon, minulla onkin laitteita ja tilejä varmaan keskivertoa enempi, johtuen kouluttajataustastani. Tästä syystä olen katsonut oma tietoturvapäivän välttämättömäksi ja hyödylliseksi. Onneksi tietyt asiat on automatisoitu palvelujen toimesta, esimerkiksi varmuuskopiointi on nykyään todella helppoa.

Suosittelen itse kunkin miettimään säännöllisesti omien laitteidensa sekä tilien tietoturvaa.

**Hyvää oma tietoturvapäivää, se on esimerkiksi tänään!**
