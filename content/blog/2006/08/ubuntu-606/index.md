Asentelen juuri pieneen testikoneeseeni uutta Linuxia, vanha Debian sai tehdä tilaa uudemmalle versiolle. Asennus meni helposti heittämällä, nyt täytyy alkaa muistella taas komentoja, jotta saa asennettua siihen tarvittavaa softaa. Apache, PHP, MySQL tarvitaan ja sitten varmaan Wordpress myös jossain vaiheessa.

Olikohan se `sudo apt-get install apache2`?

Kyllä :) Heti lähti Apache käyntiin ja vanha osoitekin on edelleen toiminnassa [http://teuvo.dyndns.tv/](http://teuvo.dyndns.tv/)

Pienen verryttelyn jälkeen onnistuin myös KDE:n ja muutaman muun siihen kuuluvan paketin asentamiseen, varsinkin tuo Synaptic Package Manager tuntuu kätevältä, vaikka juuri ja juuri muistin sen apt-getinkin käytön.
