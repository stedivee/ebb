Sain valmiiksi ensimmäisen kappaleeni tässä aloittamassani hitaasti ja satunaisesti etenevässä äänitysprojektissa. Otin työstääkseni kappaleen, jonka tein kymmenen vuotta sitten, helmikuussa 2004. Tätä ollaan soitettu myös Slow Enough -bändin kanssa, mutta tässä oma versioni ;)

https://soundcloud.com/stedi/kardiologiaa

## Kardiologiaa

```
Oli pitkä kuuma kesäkun Pariisin junassa me tavattiinjuteltiin ja siellä ihastuin sun keinuvaan lanteeseen
```

```
Eurooppaa me kierreltiinteltassa nukuttiin, paljon suudeltiinja Amsterdamissa annoin tatuoida sun nimes mun ranteeseen
```

```
Suomeen lopulta me palattiinkesä ohi oli, satamassa halattiinja sovittiin että pian tavattaisiin kaupungilla uudelleen
```

```
Ootin kauan sinuakunnes sielussani tunsin viluasillä tajusin ettet enää tule mun luokseni ollenkaan
```

```
Ensin näytit minulle taivaan ja sytytit mun kipinän
nyt pitäis löytää parannusta vaivaan, maailman pahimman ikävän
```

```
Kului siinä viikkoja kunnes mäkaupungilla tutun lanteen näinolit polttariporukan kuningatar ja suudelmia myymässä
```

```
Eri nimellä sut tunnettiinsuudelmajonossa kuulin kun sua huudeltiinostin eurolla sinulta katkeran kuuman suudelman viimeisen
```

```
Ja mä käytin plastiikkakirurgiaa ja sain sun nimesi poismutten löytänyt kardiologiaa, joka sydämeni parantais
```
