Tänään on virallinen julkaisupäivä Adoben ohjelmistojen lippulaivasta, Creative Suitesta, CS3. Tuotetta voi ennakkotilata, eli vielä sitä ei saa kokeiltavaksi. Todella mielenkiinnolla itse odotan ainakin uutta Dreamweaveriä ja Contributea, mitä kaikkkea niihin onkaan laitettu, olisiko Contributesta tullut 4-version jälkeen vielä jotain uutta? Spry on jollain tapaa DW:ssä mukana, näin ainakin näin Adoben sivuilla informaation kertoo Dreamweaveristä:

- Spry framework for Ajax
- Spry data
- Spry widgets
- Spry effects
- Adobe Photoshop® and Fireworks® integration
- Browser Compatibility Check
- CSS Advisor website
- CSS layouts
- CSS management
- Adobe Device Central CS3

Tänään 27.3.2007 on webcast julkaisutilaisuudesta klo 22:30 Suomen aikaa (3:30 itärannikon aikaa) osoitteessa [http://www.adobe.com/products/creativesuite/launchevent/webcast/](http://www.adobe.com/products/creativesuite/launchevent/webcast/), jaksaisiko sitä valvoa sinne asti näin pahasti flunssaisena?

No jaksaahan sitä, oli hyvä show vaikka olikin pieni katkos teknisien ongelmien vuoksi.
