Chris Pederick on päivittänyt erinomaisen Firefox lisäohjelman Web Developer Toolbarin versioon 1.1.4 Lue lisää [Chrisin blogista](http://chrispederick.com/blog/2007/05/11/web-developer-114-and-user-agent-switcher-0610/) Tämä add-on löytyy päivityksenä tietty suoraan Mozillan sivustolta.

Niin ja sittenhän jo hyvän aikaa on Operalle ollut omansa eli [Developer Console](http://dev.opera.com/tools/).

Myös Microsoft on tuonut vihdoin virallisemman version omastaan, eli [Internet Explorer Developer Toolbar](http://www.microsoft.com/downloads/details.aspx?FamilyId=E59C3964-672D-4511-BB3E-2D5E1DB91038&displaylang=en) -työkalustaan.
